# Arduino-ESP32 Board Files

[English](README.md) | [简体中文](README_ZH.md)

Provides the `waveshare_esp32_p4_wifi6_db` board entry and pin variant for Arduino-ESP32 `3.3.11`.

1. Copy `variants/waveshare_esp32_p4_wifi6_db` into your Arduino-ESP32 `variants/` directory.
2. Merge the `waveshare_esp32_p4_wifi6_db.*` entries from `boards.txt` into your Arduino-ESP32 `boards.txt`.
3. Restart Arduino IDE and select `Waveshare ESP32-P4-WIFI6-DB`.
