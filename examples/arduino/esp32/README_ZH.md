# Arduino-ESP32 板级支持文件

[English](README.md) | [简体中文](README_ZH.md)

提供适用于 Arduino-ESP32 `3.3.11` 的 `waveshare_esp32_p4_wifi6_db` 开发板定义与引脚变体文件。

1. 将 `variants/waveshare_esp32_p4_wifi6_db` 复制到 Arduino-ESP32 安装目录的 `variants/` 下。
2. 将 `boards.txt` 中 `waveshare_esp32_p4_wifi6_db.*` 条目合并到 Arduino-ESP32 的 `boards.txt` 中。
3. 重启 Arduino IDE 并选择 `Waveshare ESP32-P4-WIFI6-DB`。
